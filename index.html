Cowork Setup Guide

클로드 코워크 실습을 위한 필수 사전 설치 가이드입니다. 수업 전 Claude Desktop 로그인과 기본 개발환경 점검까지 완료해 주세요.

대상 초중급 수강생
수업 방식 온라인 실습
필수 목표 Claude Desktop 실행
권장 목표 Git · Node · Chrome
수업 전 가장 중요한 준비는 “Claude Desktop 설치 + 로그인 완료”입니다. Git, Node.js, Python, Claude for Chrome은 개발환경 실습 확장을 위한 권장 항목입니다. 설치가 막히면 브라우저 Claude로 우회 참여할 수 있습니다.

1필수 설치 3가지

필수

Claude 계정

수업 전 Claude에 로그인할 수 있어야 합니다. 기존 계정이 있다면 그대로 사용하세요.

https://claude.ai

필수

Claude Desktop

코워크 실습은 Claude Desktop 앱을 기준으로 진행합니다. 본인 운영체제에 맞게 설치하세요.

https://claude.com/download

필수

Claude for Chrome

Chrome 브라우저에서 Claude를 빠르게 활용하기 위한 확장 기능입니다. Claude 공식 다운로드 페이지에서 Chrome 항목을 확인해 설치하세요.

https://claude.com/download

2개발환경 권장 설치

우선순위 설치 항목 왜 필요한가요? 공식 링크
권장 1 Git 예제 파일 관리, 프로젝트 다운로드, 버전 관리 실습에 사용합니다. git-scm.com
권장 2 Node.js LTS 웹앱, 자동화, Claude Code 확장 실습에 사용합니다. nodejs.org/en/download
선택 Python 파일 처리, 데이터 정리, 자동화 실습 확장에 사용합니다. python.org/downloads

3설치 순서

Claude Desktop 설치

공식 다운로드 페이지에서 본인 운영체제에 맞는 설치 파일을 내려받아 설치합니다.

https://claude.com/download

Claude 로그인

Claude Desktop을 실행하고 본인 계정으로 로그인합니다. 로그인 완료 화면까지 확인하세요.

Code 또는 Cowork 화면 확인

Claude Desktop 안에서 Code, Cowork, 또는 작업 관련 탭이 보이는지 확인합니다.

Git, Node.js 설치

처음 설치하는 분은 Git → Node.js LTS 순서로 진행하면 됩니다. Python은 가능한 분만 선택 설치하세요.

Claude for Chrome 설치

Chrome 브라우저를 사용하는 분은 Claude 공식 다운로드 페이지에서 Chrome 확장 기능을 함께 설치해 주세요.

https://claude.com/download

설치 확인 명령어 실행

Windows는 PowerShell, macOS는 Terminal에서 아래 점검 명령어를 실행합니다.

4Windows 점검 명령어

Windows 사용자는 PowerShell을 열고 아래 명령어를 한 줄씩 입력해 주세요.

git --version
node --version
npm --version
python --version
py --version

Python은 python --version 또는 py --version 중 하나만 표시되어도 괜찮습니다.

5macOS 점검 명령어

macOS 사용자는 Terminal을 열고 아래 명령어를 한 줄씩 입력해 주세요.

git --version
node --version
npm --version
python3 --version

git --version 입력 후 설치 안내가 뜨면 Xcode Command Line Tools 설치를 진행해 주세요.

Claude Desktop에서 로그인을 완료했습니다.

Claude for Chrome을 설치했습니다.

Python은 가능한 경우에만 설치하고 버전을 확인했습니다.
